# แบรนด์และสินค้า

ชื่อสินค้า: skillz (Sonar skills สำหรับ Claude Code)
ลิงก์: https://github.com/wutgii-worawut/skillz (ลิงก์หน้าโปรไฟล์)
คำสั่งติดตั้ง: npx skills add wutgii-worawut/skillz -a claude-code

ปัญหาของลูกค้า: Sonar ฟ้อง issue เป็นร้อย ไล่แก้ไม่ไหว

จุดเด่น 3 ข้อ:
1. /sonar-report — สรุป Quality Gate + issue
2. /sonar-report-docs — เขียนรายงานเต็มลง sonar/
3. /sonar-fix — แก้ issue โดยไม่เปลี่ยน behavior

สีแบรนด์: พื้นกรมท่าเข้ม #0a0f1f, ม่วง #8b6cff, ฟ้า #22d3ee, แดง (ปัญหา) #ff4d6d, เขียว (สำเร็จ) #34d399, ตัวหนังสือ #f4f6ff
ฟอนต์: Prompt (ไทย/อังกฤษ), JetBrains Mono (โค้ด/คำสั่ง)
สไตล์: dark tech, terminal, แสงฟุ้งม่วง-ฟ้า, ตารางจางๆ เป็นพื้นหลัง
รูป: ไม่มีรูปสินค้า ใช้ terminal และการ์ดคำสั่งแทน
