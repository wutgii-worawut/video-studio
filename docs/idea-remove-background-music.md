# ไอเดีย: เอาเพลง (รวมเสียงคนร้อง) ออกจากคลิปที่มีคนคุยกัน 2–3 คน

สถานะ: **ไอเดีย ยังไม่ได้ทำ** · อาจแยกเป็น repo ใหม่ในอนาคต
บันทึกเมื่อ: 7 ต.ค. 2026

## โจทย์

มีคลิปที่คน 2–3 คนคุยกัน และมีเพลงเปิดอยู่ข้างหลัง (มีเสียงคนร้องด้วย)
อยากได้เสียงที่เหลือแค่คนพูด ไม่มีดนตรีและไม่มีเสียงร้องของเพลง

## ทำไมยาก

- เครื่องมือแยกเพลงทั่วไปแบ่งเสียงเป็น "เสียงคน" กับ "ดนตรี"
  เสียงคนร้องในเพลงกับเสียงคนพูดจึงตกไปอยู่ฝั่งเดียวกัน
- Whisper (ที่ใช้ใน video-studio อยู่แล้ว) **ทำเรื่องนี้ไม่ได้** Whisper แค่ถอดเสียงเป็นข้อความ ไม่ได้แยกเสียง

## ทางเลือก

| วิธี | ผลที่คาดไว้ | ต้องมีอะไร |
|---|---|---|
| Demucs (Meta) | ตัดดนตรีออกได้ดี แต่เสียงคนร้องในเพลงยังติดอยู่กับเสียงคนพูด | Python + PyTorch + โมเดล (หลาย GB), ใช้ GPU ได้ |
| โมเดลเน้นเสียงพูด (speech enhancement / separation เช่น DeepFilterNet, SpeechBrain) | เก็บเสียงพูด ตัดเสียงที่เป็นทำนองออก ถ้าเพลงดังพอๆ กับเสียงพูด จะเหลือเสียงร้องค้างและเสียงพูดอาจแปร่ง | Python + โมเดล |
| **ทำ 2 ขั้น: Demucs → โมเดลเน้นเสียงพูด** | น่าจะดีที่สุด: ตัดดนตรีก่อน แล้วค่อยกรองเสียงร้องที่เหลือ | ทั้งสองอย่าง |
| ElevenLabs Voice Isolator (ออนไลน์) | ใช้ง่าย ยังไม่ได้ลองกับเสียงร้องในเพลง | อัปโหลดไฟล์ขึ้นเว็บ |
| ffmpeg center-cancel | หยาบ ตัดได้แค่เสียงที่อยู่กลางสเตอริโอ และเสียงคนพูดที่อยู่กลางก็หายไปด้วย **ไม่เหมาะกับงานนี้** | มีอยู่แล้ว |

ผลลัพธ์ในตารางนี้เป็นการคาดเดาจากหลักการของแต่ละเครื่องมือ **ยังไม่ได้ทดสอบจริงกับคลิปของเรา**

## สิ่งที่ตัดสินว่าจะสะอาดแค่ไหน

- เพลงเบากว่าเสียงพูดมาก → น่าจะสะอาด
- เพลงดังพอๆ กับเสียงพูด หรือมีคนพูดทับตอนเพลงกำลังร้อง → จะเหลือเสียงร้องบ้าง ไม่มีวิธีไหนเอาออกได้ 100%

## แผนเมื่อเริ่มทำ

1. เลือกคลิปตัวอย่าง 2–3 คลิป: เพลงเบา, เพลงดัง, พูดทับตอนร้อง
2. ลองแต่ละวิธีกับคลิปเดียวกัน แล้วฟังเทียบ ผลของ ElevenLabs ใช้เป็นตัวเทียบ
3. วัดผลแบบง่ายๆ: เอาเสียงที่ได้ไปถอดด้วย Whisper ถ้าคำพูดถอดได้ครบ และไม่มีเนื้อเพลงปนมา แปลว่าใช้ได้
4. เลือกวิธีที่ดีที่สุดแล้วทำเป็นคำสั่งเดียว เช่น `node clean-voice.mjs input.mp4` → `input.voice.wav`
5. (เผื่อไว้) แยกเสียงของแต่ละคนด้วย diarization แล้วทำซับแยกตามคนพูด ต่อยอดจาก Whisper ที่มีอยู่

## ต่อกับ video-studio ยังไง

- เสียงที่ได้ใช้เป็น `brand/voice.*` ได้ทันที ระบบ lip-sync ของโมจิ (`node render.mjs <ชื่อ> voice`) และการจับเวลาด้วย Whisper ใช้ต่อได้เลย
- ถ้าแยก repo: ให้เป็นเครื่องมือเล็กๆ ที่ส่งไฟล์เสียงออกมาไฟล์เดียว video-studio ไม่ต้องรู้ว่าข้างในแยกเสียงยังไง

## ข้อควรระวัง

- การติดตั้ง Python, PyTorch และโมเดลต้องถามผู้ใช้ก่อน (กฎใน CLAUDE.md)
