# cute-doodle — Kawaii Doodle Animation

การ์ตูนวาดมือน่ารัก เส้นปากกาดำสั่นดุ๊กดิ๊ก สีพาสเทลบนกระดาษ ตัวละครกลมๆ เด้งดึ๋ง
ตัวอย่าง: `example.png` · โปรเจกต์อ้างอิง: `projects/mochi-monday`

## หน้าตา
- พื้น: กระดาษครีม `#fff8ec` + ลายจุด `radial-gradient(#e8d9c2 4px, transparent 5px)` ขนาด 60px เลื่อนช้าๆ
- เส้น: หมึก `#2b2b2b` หนา 8 (เส้นรอง 5–6) `stroke-linejoin/linecap: round` ทุกเส้น
- สี: พีช `#ffb4a2` · มิ้นต์ `#a8e6cf` · เหลืองเนย `#ffe08a` · ฟ้า `#a0d2ff` · แก้มชมพู `#ff9eb5` · คอรัล (หัวข้อ) `#ff8a7a`
- ฟอนต์: Mali 600/700 (ลายมือไทย)
- ตัวหนังสือแบบสติกเกอร์: ขอบสีกระดาษ 8 ทิศ + เงาจางเยื้องขวาล่าง
  `text-shadow: ±5px ±5px 0 paper, 0 ±6px 0 paper, ±6px 0 0 paper, 8px 9px 0 #00000022`
- กล่องคำพูด: พื้นขาว ขอบหมึก 7px มุมโค้งมาก + วงกลมเล็ก 2 วงแทนหาง (แบบ thought bubble)
- ป้าย: พื้นเหลืองเนย ขอบหมึก 7px ทรงแคปซูล
- ของตกแต่ง: ดาวสี่แฉก หัวใจ ไอร้อนเส้นหยัก แสงหมุน (sunburst) เหลืองเนยโปร่ง

## Line boil (หัวใจของแนวนี้)
`boil.js` ในโฟลเดอร์นี้ — ใส่ `<script src="../../../styles/cute-doodle/boil.js"></script>` ต่อจาก `<body>`,
class `boil` บนภาพวาด, `boilT` บนตัวหนังสือ, เรียก `Boil.update(t)` ใน `render(t)` → เส้นสั่นใหม่ 8 ครั้ง/วินาที

## ตัวละคร
ทรงกลมเตี้ย หัวกับตัวเป็นก้อนเดียว หูสามเหลี่ยมมีชมพูด้านใน ตาเป็นจุด/เส้นโค้ง แก้มชมพูวงรี ปากรูป w หนวด 2 เส้นต่อข้าง
สร้างจากฟังก์ชันที่สลับตา/ปากได้ (หลับ ง่วง ประกาย ^ ^) และมีแขนยกได้ — ดูฟังก์ชัน `mochi()` ใน mochi-monday เป็นแม่แบบ
ท่าทางต้องเล่าเรื่องเอง (ยกแก้วซด, โบกมือ, กระโดด) ไม่ใช่ปล่อยให้คำพูดเล่าแทน

## การขยับ
- เข้าฉาก: `spring` / `back` เด้งเกินนิดแล้วกลับ, ตัวหนังสือขึ้นทีละคำ (`FX.words`) หรือทีละตัว (`FX.chars`)
- มีชีวิตตลอด: หายใจ (scaleY ±2–3%), เดินโยก, กระโดด squash & stretch, ของตกแต่งหมุน/กระพริบ
- วาดเส้นขึ้นเอง (`FX.draw`) สำหรับพื้น เส้นใต้ ไอร้อน
- เปลี่ยนฉาก: whip → zoom → circle (ไม่ซ้ำกัน) ฉากที่รับ circle ต้องมีพื้นทึบ
- กล้อง: ซูมเข้า 8% ตลอดคลิป + สั่นตอนเสียงดัง/พลังเต็ม

## เสียง
pop ทุกอย่างที่เด้งเข้า · ding ตอนของดีโผล่ · whoosh ตอนเปลี่ยนฉาก · tick ตอนนับ/เติม · impact ตอนจุดพีค
เสียงเฉพาะเรื่องสังเคราะห์ด้วย ffmpeg ลง `brand/sfx/` (เช่น ring นาฬิกาปลุก, sip เสียงซด ใน mochi-monday)
