# dark-tech — Dark Tech / Terminal

โปรโมทเครื่องมือนักพัฒนา: พื้นกรมท่าเข้ม แสงฟุ้งม่วง-ฟ้า ตาราง terminal และการ์ดคำสั่ง
ตัวอย่าง: `example.png` · โปรเจกต์อ้างอิง: `projects/skillz-promo`

## หน้าตา
- พื้น: กรมท่าเข้ม `#0a0f1f` + ตารางจาง `#ffffff0a` ช่อง 90px เลื่อนขึ้นช้าๆ
- แสงฟุ้ง: วงกลม 900px `blur(140px)` ม่วง `#8b6cff` และฟ้า `#22d3ee` ลอยไปมาด้วย sin/cos
- สี: ตัวหนังสือ `#f4f6ff` · รอง `#9aa3c7` · ฟ้า (คำสั่ง/ชื่อสินค้า) `#22d3ee` · แดง (ปัญหา) `#ff4d6d` · เขียว (สำเร็จ) `#34d399`
- ฟอนต์: Prompt 400/600/800 (ไทย/อังกฤษ) · JetBrains Mono 500/700 (โค้ด/คำสั่ง)
- terminal: การ์ดมุมโค้ง 32px พื้น `#0f1630` ขอบ `#ffffff1f` แถบบนมีจุดแดง-เหลือง-เขียว พิมพ์คำสั่งทีละตัวพร้อมเคอร์เซอร์ ▌
- การ์ดจุดเด่น: พื้น `#ffffff0d` ขอบ `#ffffff1a` มุม 30px ชื่อคำสั่ง mono สีฟ้า + คำอธิบายสีรอง + เลขกลมสีม่วงมุมขวา
- โลโก้ปิดท้าย: ตัวใหญ่ไล่สีม่วง→ฟ้า (`background-clip:text`) + เส้นหยักวาดใต้ + ปุ่มขาวทรงแคปซูล

## การขยับ
- ปัญหาเปิดเรื่อง: คำใหญ่ขึ้นทีละคำ, ประโยคพีคตกลงมาแบบ spring จากขนาด 1.9 เท่า + กล้องสั่น, ตัวเลขนับขึ้น
- การ์ดเลื่อนเข้าจากขวาแบบ spring พร้อมเบลอ, ไฮไลต์ปาดใต้ชื่อสินค้า
- เปลี่ยนฉาก: zoom (ทะลุเข้า) → circle (เปิดฉากปิดท้าย) ฉากที่รับ circle ต้องมีพื้นทึบ
- ปิดท้าย: โลโก้ spring + confetti + ปุ่มเต้นเบาๆ

## เสียง
tick ทุกตัวอักษรที่พิมพ์ · ding ตอนติดตั้งสำเร็จ/โลโก้ · whoosh การ์ดและหัวข้อ · impact ประโยคพีคและโลโก้ · pop ป้ายเล็ก
