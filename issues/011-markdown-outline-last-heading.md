# 011 · สารบัญ Markdown ไม่ไฮไลต์หัวข้อท้ายไฟล์ที่คลิก

- วันที่: 2026-10-11
- tags: editor, page, markdown
- project: ทุกโปรเจกต์ (เทสต์ใช้ไฟล์ชั่วคราวใน composition-demo/docs)

## ปัญหา
ในโหมด Preview ของ Code เมื่อคลิกหัวข้อสุดท้ายในสารบัญ (Outline) ซึ่งอยู่ท้ายไฟล์ หน้าเลื่อนลงไปถูกที่ แต่แถบไฮไลต์ไปค้างอยู่ที่หัวข้อก่อนหน้า
`tests/react-markdown.test.mjs` บางรอบผ่าน บางรอบค้างที่ `.outline-row.active` "Last heading" (ล้มบ่อยขึ้นหลังเพิ่ม KaTeX/highlight CSS)

## สาเหตุ
`Outline` ใน `MarkdownView.tsx` ถือว่าหัวข้อปัจจุบันคือหัวข้อสุดท้ายที่ขึ้นไปถึงขอบบน + 48px แต่หัวข้อที่อยู่ท้ายไฟล์เลื่อนขึ้นไปถึงขอบบนไม่ได้ เพราะเนื้อหาด้านล่างไม่พอ พอ scroll event ทำงานจึงเขียนทับค่าที่ตั้งตอนคลิก ส่วนที่บางรอบผ่าน น่าจะเป็นเพราะ scroll event มาถึงก่อนหรือหลัง `setActive` ตอนคลิกไม่เหมือนกันในแต่ละรอบ

## วิธีแก้ที่ได้ผล
- ถ้าเลื่อนจนสุดท้ายแล้ว (`scrollTop+clientHeight >= scrollHeight-2`) ให้ใช้ขอบล่างของพื้นที่อ่านเป็นเส้นตัดแทนขอบบน จะได้หัวข้อล่างสุดที่มองเห็นเป็นหัวข้อปัจจุบัน
- ตรวจแล้ว: `node --test tests/react-markdown.test.mjs` ผ่าน 3 รอบติดกัน (2/2 ทุกรอบ)
