# 004 · เส้นฟ้าบาง ๆ ขอบซ้ายล่างตอนต้นคลิป

- วันที่: 2026-10-10
- tags: page, layout, transition
- project: sword-of-coming-s3
- ref: -

## ปัญหา
วินาทีที่ ~0.5–0.7 (ฉากเปิด) มีเส้นแนวตั้งสีฟ้าบาง ๆ ที่ขอบซ้ายล่างของจอ ผู้ใช้เห็นตอนเล่นในเบราว์เซอร์

## สาเหตุ
- ฉากที่เข้าด้วย `wipe` (และ `circle`) ใน `FX.scenes` (lib/fx.js) ไม่ได้ซ่อนก่อนถึงเวลาเข้า: opacity ยังเป็น 1 แค่ถูก clip-path เป็นรูปกว้าง 0 ที่ x=0
- ฉาก s-zuoyou มีน้ำสีฟ้าลากถึงขอบซ้าย ขอบ clip ที่กว้าง 0 จึงยังวาดออกมาเป็นเส้นบาง 1px
- ที่ 0.6 วิ กล้องสั่น (shake 12px) ทำให้ขอบ x=0 โผล่เข้ามาในจอ เลยเห็นเส้นนั้น

## วิธีแก้ที่ได้ผล
- ใน `render(t)` ของหน้า หลัง `FX.scenes(...)` และบรรทัด WHIP_OUT ใส่:
  `for (const [sel, tin] of SCENES) if (t < tin) $(sel).style.visibility = 'hidden';`
- ตรวจแล้ว: ที่ 0.6/0.7 วิ เหลือฉากที่มองเห็นแค่ s1 และไม่มีเส้นที่มุมซ้ายล่าง
- ยังไม่ได้แก้ที่ lib/fx.js ถ้าแก้ที่นั่น (wipe/circle ตอน p <= 0 ให้ op = 0) จะครอบทุกโปรเจกต์
