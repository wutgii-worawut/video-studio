# 014 · หน้า Code พังเป็นคอลัมน์เดียวตอนจอแคบในโหมด Markdown Preview

- วันที่: 2026-10-11
- tags: layout, editor, markdown
- project: ทุกโปรเจกต์
- ref: 011

## ปัญหา
ตอนเพิ่มการแสดงสารบัญเมื่อจอ ≤ 1100px ที่ความกว้าง 1000px หน้า Code กลายเป็นคอลัมน์เดียว ต้นไม้ไฟล์อยู่บน สารบัญไปอยู่ล่างสุด ทั้งที่ `grid-template-columns` คำนวณออกมาเป็น 3 คอลัมน์ เทสต์ที่เช็กแค่ `isVisible()` ยังผ่าน

## สาเหตุ
ชื่อ class ชนกัน: ใช้ `md-outline` ทั้งเป็นตัวแก้ layout ของ `.code-page` และเป็น class ของ `<nav>` สารบัญที่ตั้ง `display:flex` ไว้ `.code-page` จึงเปลี่ยนจาก grid เป็น flex

## วิธีแก้ที่ได้ผล
- เปลี่ยนชื่อตัวแก้ layout ของหน้าเป็น `md-with-outline`
- เทสต์เช็กตำแหน่งด้วยว่าสารบัญอยู่ข้างเนื้อหา (ค่า x ของสารบัญมากกว่าขอบขวาของบทความ)
- ตรวจแล้ว: ภาพหน้าจอที่ 1000px ได้ 3 คอลัมน์, `tests/react-markdown.test.mjs` ผ่าน 2/2
